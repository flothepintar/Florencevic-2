# Florencevic Pondaag Portfolio

Personal portfolio for Florencevic Pondaag — Technology & E-Commerce Manager.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
npm start
```
